# DANCE & SHAPE 更新版

## 追加機能
- 食事記録（kcal・PFC・食事区分）
- 体重の推移グラフ
- 摂取カロリーと推定消費カロリーの7日間グラフ
- 年齢・性別・身長・活動量からの消費カロリー推定
- 時短レシピと材料の買い物リストへの追加
- 買い物リストの購入済みチェック
- 週間食事準備ガイド（週単位でチェック状況を保存）
- 既存の運動メニュー・体重/身体記録を維持

## iPhoneへの反映
1. このZIPを展開し、公開中のサイトにある同名ファイルを更新してください。
2. iPhoneのSafariでアプリを開き直してください。
3. 表示が古い場合は一度ページを再読み込みしてください。Service Workerのキャッシュ名はv2に更新しています。

## データについて
- 既存の `localStorage` キー `ds-data` を引き継ぎます。体重・運動記録を維持する設計です。
- 食事・買い物・プロフィール・週間準備チェックも端末内に保存します。
- ブラウザのデータ消去や端末変更で失われる可能性があります。別端末同期やクラウドバックアップはありません。
- 消費カロリーはMifflin-St Jeor式と活動係数による概算です。医療・栄養指導の代替ではありません。
- 月曜日の準備ガイドはアプリを開いた際に表示されます。アプリを閉じていても通知が届く機能ではありません。
